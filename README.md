# Finanças Pro

Aplicativo web para controlar gastos, cartões, dívidas, metas e clientes. Funciona no celular e no computador.

## Arquivos
- `index.html` — telas e janelas do app
- `app.js` — toda a lógica (único arquivo; tem um índice no topo com as seções)
- `style.css` — todo o visual (claro e escuro)
- `sw.js` + `manifest.json` — uso offline e instalação na tela inicial
- `img/` — ícones e fotos

## Como usar
Abra `index.html` pelo navegador. Para uso offline e instalação, hospede os arquivos em um endereço http(s).
Faça backup em Menu > Sistema > Exportar Dados.
